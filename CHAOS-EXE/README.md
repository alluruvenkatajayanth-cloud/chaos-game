# CHAOS.EXE

A browser-based interactive experiment built with plain HTML, CSS and JavaScript.

## Features
- 24 discoverable anomalies
- 12 achievements
- 6 chaos stages
- Local save system with localStorage
- Particle explosions
- Sound toggle using Web Audio API
- Secret events and easter eggs
- Event archive
- Hidden terminal
- System overload at 100+ clicks
- Responsive layout
- No backend and no dependencies

## Run locally
Open `index.html` in a modern browser.

## Deploy
This is a static website. It can be deployed directly to Vercel, Netlify, GitHub Pages, Cloudflare Pages, or any static host.
